DNSLogHUB API 文档

DNSLogHUB 提供 DNS / HTTP / LDAP / RMI 多协议外带数据捕获，接口统一返回 JSON： {"code": 200, "msg": "success", "data": ...}

1. 鉴权

除 /api/verifyToken、/api/register、/api/ip 外，其余接口需在请求头携带 token：

token: your_token

2. 注册（可选，需开启 Register.enabled）

POST /api/register，需邀请码：

curl -X POST http://localhost:8000/api/register \
  -H 'Content-Type: application/json' \
  -d '{"token":"my_token_123","subdomain":"mylog","inviteCode":"INVITE-CODE"}'

3. 接口一览

方法 路径 鉴权 说明
ANY/api/verifyToken否校验 token，返回子域名
POST/api/register否用户注册（邀请码）
GET/api/ip否查询本机来源 IP 归属
GET/api/ip/:ip否查询指定 IP 归属
ANY/api/getDnsData是获取全部记录
ANY/api/clean是清空记录
ANY/api/getDnsData_clear是取后即清
POST/api/verifyDns是验证单条 DNS
POST/api/bulkVerifyDns是批量验证 DNS
POST/api/verifyHttp是验证单条 HTTP 回调
POST/api/bulkVerifyHttp是批量验证 HTTP
POST/api/setARecord是临时设置 A 记录
POST/api/setTXTRecord是临时设置 TXT 记录

4. 调用示例

4.1 验证 Token

curl -X POST http://localhost:8000/api/verifyToken \
  -H 'Content-Type: application/json' \
  -d '{"token":"admin"}'
import requests
r = requests.post('http://localhost:8000/api/verifyToken', json={'token': 'admin'})
print(r.json())

4.2 生成随机子域名并验证回连

# 1) 解析随机子域名，例如 abc123.mylog.example.com
# 2) 在目标上触发该域名的解析后，验证是否收到回连
curl -X POST http://localhost:8000/api/verifyDns \
  -H 'token: your_token' -H 'Content-Type: application/json' \
  -d '{"query":"abc123.mylog.example.com"}'

4.3 SSRF / 外带探测对接

访问 http://<host>/<subdomain>/<随机串> 触发 HTTP 回调，再验证：

curl -X POST http://localhost:8000/api/verifyHttp \
  -H 'token: your_token' -H 'Content-Type: application/json' \
  -d '{"query":"/mylog/abc123"}'

5. 错误码与限流

  • 200 成功（业务 msg=Not Found 表示未命中记录）
  • 400 请求参数不合法
  • 401 token 无效（HTTP 状态为 401，接口层 code=401）
  • 403 邀请码无效 / 注册未开启
  • 409 token 或子域名冲突
  • 429 触发限流（注册默认每 IP 每分钟 5 次）

6. 对接渗透测试工具

  • SQLMap 外带：将 --dns-domain 或注入 payload 中的域名替换为随机子域名，命中后经 /api/getDnsData 读取。
  • Nuclei / 自定义模板：将占位符替换为 DNSLogHUB 随机子域名，配合 /api/bulkVerifyDns 批量确认。
  • Burp Collaborator 替代：payload 中注入 <随机>.<你的子域>.<域名>，通过本平台观察 DNS/HTTP 回连。
  • Go SDK：pkg/sdk 提供 NewDnsLogClient / VerifyDns / VerifyDnsV2（批量）等方法。
